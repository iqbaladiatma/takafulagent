## 🔧 Jika Ada Masalah

### CSS tidak muncul?
```bash
npm run build
php artisan optimize:clear
```

### Tampilan masih lama?
```bash
php artisan optimize:clear
php artisan filament:optimize-clear
```

### Refresh browser
Tekan `Ctrl + Shift + R` (Windows) atau `Cmd + Shift + R` (Mac)

## 📝 Tips Penggunaan

1. **Upload Foto Berkualitas**
   - Gunakan foto profil yang jelas
   - Rasio 1:1 (persegi)
   - Max 2MB

2. **Nomor WhatsApp**
   - Format: 08123456789 atau +628123456789
   - Link WA akan auto-generate

3. **Deskripsi Menarik**
   - Tulis deskripsi yang profesional
   - Highlight pengalaman dan keahlian

4. **Update Berkala**
   - Perbarui data agen secara rutin
   - Pastikan nomor telepon aktif
