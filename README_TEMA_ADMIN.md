## 🔧 Troubleshooting

### CSS tidak muncul?
```bash
npm run build
php artisan optimize:clear
```

### Tampilan masih lama?
```bash
php artisan filament:optimize-clear
```

### Refresh browser
```
Ctrl + Shift + R (Windows)
Cmd + Shift + R (Mac)
```
