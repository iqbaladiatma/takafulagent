## 🎨 Visual Hierarchy

### Shadow Levels
```
Level 1: Flat
- 0-2px shadow
- Untuk text, icons

Level 2: Raised
- 2-8px shadow
- Untuk buttons, badges

Level 3: Floating
- 8-20px shadow
- Untuk cards, widgets

Level 4: Modal
- 20-60px shadow
- Untuk modals, dropdowns
```
